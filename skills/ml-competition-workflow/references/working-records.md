# 可接续记录模板

这些是按需选用的简版模板，不要求每个任务创建全部文件。已有日志、配置或追踪系统能提供同等证据时直接引用。

## 比赛起始记录

```text
比赛与任务 / 当前阶段 / 截止日期和时区：
官方指标版本、合法产物、资源上限：
真实独立单位 / 隐藏迁移方向 / 标签缺失语义：
允许训练池 / 各底座暴露 / 开发、独立验证、最终拟合角色：
最强有效基线：精确代码、配置、权重、提交版本与已核实成绩
用户授权：训练预算、数据范围、GPU/进程、运行/提交、监控边界
尚缺证据及其影响：
```

## 一轮实验卡

```text
ID / 日期 / 当前正式基线：
假设与证据（事实、推断分开）：
可恢复错误 / 新增信息 / 为什么优先于其他方向：
主要改动 / 固定项 / 实际部署接入位置：
数据池 / 预计唯一消费 / 总曝光 / 组覆盖 / 排除规则：
训练与执行预算 / 停止或复审节点：
实现检查 / 非零路径一致性：
最终主指标、分组风险 / 复现容差 / 效果阈值：
通过、失败、无效或证据不足分别怎样处理：
允许的外部动作：
```

## 结果与方向账本

|字段|记录内容|
|---|---|
|身份|实验ID、代码/配置/资源哈希、正式checkpoint、命令、目录|
|状态|实际达到的运行/评估/推送/提交/评分状态与ID|
|覆盖|实际唯一消费、总曝光、监督可用和来源组；与计划差异|
|实现|核验结果及未通过项；失败不能作为模型效果|
|效果|正式基线对照、总指标、分项、独立组及阶段变化|
|证据等级|我方复现、官方/API、作者报告、推断、未知|
|决策|保留、晋级、独立确认、转向、停止；依据是什么|
|边界|共同改变、开发重复使用、来源缺失、隐藏规模未覆盖|

多轮同方向归在同一账本，明确上轮假设是否被否定。不要让文件越来越多却看不到当前最佳有效候选、待解决瓶颈和停止理由。

## 比赛复盘

1. 目标与实际结果；区分模型效果、验证质量和提交可靠性。
2. 时间线与可核实实验表；不同验证口径不混算。
3. 数据池、实际消费、独立单位、底座暴露和角色变化。
4. 每个根因的证据、替代解释、当时是否可知及错过的决策点。
5. 公开方法的新信息与接入差异；赛后可见不等于赛时可得。
6. 哪些工程做法有效，哪些研究/执行流程应改变。
7. 将纠正措施绑定到下一比赛的触发条件、动作、验收和负责人，而不是泛泛列“多看论文”。
8. 不具备证据的结论明确保留；不承诺新流程必然获奖。
