# Biohub 2026案例：流程动机

依据2026-09-30保存的实验和提交审计；这里是项目案例，非全部参赛团队的统计，也不是冠军完整解法。未取得最终前三完整方案，不推断最终私榜名次。

## 已核实的现象

- 原适配器训练池423窗口/72视野；扩展930窗口/166视野，4096步实际访问882窗口。166视野只来自两个胚胎。
- 五/十二视频长期反复开发；副模型原训练包含全部十二开发视频。排除新增训练中的视频不能消除底座暴露。
- 8569个有效父目标，基线在已知父子集仅5个最高分错误；全候选竞争不一致201例，198例最高竞争者unknown。后者不是198条可信负边。
- 一轮边残差训练对2883条端点完整GT关系未改变父排名，却让255条边向上跨过候选阈值。局部校准变化不等于可恢复关联收益。
- 一系列五视频实验的adjusted-edge约0.9207–0.9218；去概率输入边头比基线仅高约8.7e-7，普通关联与分裂TP/FP未改善。
- 后期完整172视频训练覆盖17200帧；195最终拟合吸收开发视频，其开发结果属于训练内回归。
- 团队可见提交快照共116条，103条有效公榜分、13条错误。最高有效公榜0.956；这不是所有失败都由同一人或同一方法造成，也不是最终私榜证明。

## 应改变的决定

1. 先查共享来源和预训练名单，再谈独立验证。官方明确隐藏测试胚胎不同，因此同胚胎视野扩大不能自动证明迁移增强。
2. 难例监督缺失时，停止以更多头/系数代替信息增量；保留unknown，不把教师或评估FP转成GT负例。
3. 优化分裂先查候选可达和下游保留；优化定位先查改动接入位置。前置坐标会改变关联输入，后置校正则是不同假设。
4. 实现可复现仍可能方向低价值。应设置方向复审，而不是把每个失败都变成下一轮相近结构。
5. 占位推理通过不能代替隐藏规模验收，Notebook完成不等于比赛有效评分。

- [Tom公开代码](https://www.kaggle.com/code/tom99763/merge-safe-tko-o12-ilpdiv04-readmit094-biohub)：图处理结束后有界追加分裂，使用定向时序图像证据；还包含后置坐标偏移。只确认代码行为和作者自述，未独立复现其OOF增益或绑定最终排名。
- [B251定位头](https://www.kaggle.com/code/malikhammadfarooq/biohub-f4-w7s115-int)：将局部检测logits峰形状补丁加入定位输入，并融合新旧坐标头。
- [官方数据定义](https://www.kaggle.com/competitions/biohub-cell-tracking-during-development/data)：目录前缀标识胚胎，训练与隐藏测试胚胎隔离；可见test为占位副本。

这些不是后续比赛必须使用的技巧。可迁移的经验是先检查信息、监督、接入、独立验证和最终产物，再决定结构与预算。
