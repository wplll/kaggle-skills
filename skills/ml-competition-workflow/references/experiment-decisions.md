# 从证据选择实验

## 原始来源差异表

对影响下一步的公开方案记录：来源URL、作者、查询日期、首次公开时间（无法确认则未知）、精确代码/资源版本、实际启用模块、训练数据/划分、作者本地结果、已绑定的榜单成绩、与当前基线差异和复现成本。

区分作者自述、代码证据、我方复现和API评分；Notebook标题/排名排序/最后运行时间不能分别替代真实成绩/获奖名次/首次公开时间。检查被生成的代码、环境覆盖和后续重定义，不能只读一个常量或过期注释。论文结果必须和本比赛标签、任务、资源对应后才形成实验。

看到外部方案有效时，先确定它添加了什么信息，在哪个阶段影响决策，再考虑复用。不要把多个共同改动的总体增益分配给一个技巧，也不要把所有高级模块假定为已开启。

## 可恢复收益与接入探针

按管线拆解：输入/检测 → 候选 → 排序/打分 → 融合 → 离散决策 → 后处理 → 导出/计分。对拟议方向，优先复用已有输出检查：

1. **覆盖：**正确目标是否存在、候选是否包含它？缺失时排序训练解决不了该错误。
2. **信息：**现有特征是否看得到用于区分竞争者的证据？时序/形态摘要未必保留事件信号。
3. **监督：**目标与可靠竞争标签是否足够、是否集中于少数来源？有效样本而非组合数量决定信息量。
4. **传播：**改动经过后续阶段是否保留？局部梯度能到达不代表最终决策能改变。

可用oracle或强制约束估计可达空间，但只在明确标记的诊断输出中使用GT，不携带到实际推理。保持候选合法约束，非最优求解状态不能当作机制证明。

例如：关联概率变尖却父排名不变，应检查阈值穿越及最终换边；定位改善但连边下降，应区分前置坐标影响与后置导出校正；分裂被重连抹去，应验证接口，再判断是否有可靠事件选择证据。不要一边改候选、一边改评分和过滤，却声称是单因素实验。

## 实验卡：最少需要的决定

选择一个与本轮目标相称的规模，写下假设、证据、有效对照、唯一主要改动、不得改变项、样本池与消费预算、主指标/分组风险、实现检查、效果判据、终止与下一步条件。采用[working-records.md](working-records.md)中的简版即可。

预算不是机械固定4096步或某个seed。用任务收敛、数据覆盖和资源决定；用户指定时遵守。改变数据曝光与结构等多个维度若有实际必要，就明确是组合实验，不伪装消融。

排序实验优先考虑：预期可恢复错误、证据可靠性、信息增量、投入成本和剩余时间。数值打分表可辅助，但不把主观权重伪装成精确概率。保留一个有充分理由的新方向，避免全部预算锁死在当前路线的微调。

## 训练诊断与一致性

依任务检查训练目标与实际输出的归一化、融合、掩码、多正例、padding及后处理接口。教师KL可约束漂移，但不能自动提供缺失真值；小梯度/小残差不保证安全。

使用固定探针比较同一目标集合的变化，再解释loss。检查有效梯度、优化器/EMA包含范围、冻结缓冲区、初始化以及非零模型训练—推理一致性。恢复时验证目标、结构、数据/采样、来源和语义配置。

只为脆弱实现做必要检查，避免每个低风险改动都重跑全部历史测试。代码/权重哈希证实身份；代码确有预期修改时记录新旧差异，不以笼统“兼容”跳过来源检查。

## 效果与停止

报告官方总指标、关键分项、按独立来源分组及预先定义的风险项。阶段指标首次变化是定位证据，不等于逐样本因果证明。坐标匹配变化、物理预测变化、节点过滤和计分规则效应分开解释。

不自动把所有TP不降/FP不升设为跨比赛通用门槛；它是一种风险偏好，可能排除总目标有效权衡。事前说明并保留用户明确门槛。复现误差与效果阈值分离；不因优于失败候选就越过正式基线。

根据预算设方向复审点。若连续实验只有校准漂移、监督覆盖饱和、最终输出不变或本地/线上不一致，应转向瓶颈审计、补信息、换任务/接口或结束，而非自动搜索新系数。停止后写清已排除和仍未区分的机制。

不要无限诊断：若已知事实足够选定一个获授权的低成本实证试验，启动它。每项诊断都应绑定一个可改变的决定。额外折/seed/数据扩扫需要处于现有授权和预算之内。
