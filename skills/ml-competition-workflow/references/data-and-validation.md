# 数据、监督与验证

## 识别真实独立单位

读取官方数据定义及原始元数据，建立 `record → source group → domain/time` 映射。医疗图像按患者/机构，轨迹按对象/视频来源，时序按可用时间，显微数据按胚胎/实验批次；不凭文件名猜含义。检查同源切片、相邻窗口、重复副本与派生数据。

划分模拟部署：新患者/新地点用组隔离，未来预测用时间隔离并核验特征可用时刻。分层只在不破坏独立性的前提下使用。若只有两个来源组，可以做双向迁移以发现异质性，但不能声称精确估计新域总体方差。

对下列组件分别核验暴露：主模型、副模型、教师、辅助检测器、特征提取器、伪标签生成器、校准器、归一化统计、阈值选择和集成权重。记录已知名单、未知来源及交集。公开模型见过开发数据时，它仍可用于开发回归，但全管线性能不能标为独立验证。

## 保持四种评价用途清晰

|集合/证据|允许的用途|不能据此声称|
|---|---|---|
|训练样本及固定训练探针|损失、梯度、可学习性和训练行为|泛化提升|
|开发回归集|快速排错、阶段影响、候选筛选|多轮后仍是盲测|
|独立验证/OOF|估计组外变化、稳定性、选择固定方案|所有底座无暴露，除非已核验|
|榜单反馈|隐藏样本上的有限反馈|公榜微差保证私榜排序|

记录每个验证集被查看、选参或作为训练标签使用的角色变化。不能用换名、重新划分同源帧或重新标记来制造“新验证”。

## 稀疏监督

先审计标签含义和缺失机制：未标注、显式负例、忽略区、歧义、缺失端点各是什么。建立可靠正/负/unknown规则；事件或排序任务检查完整正关系、竞争集合和多正例语义。

测量基线在受监督子集与真实部署竞争集合的差异：可达正例比例、已知子集错误、全候选错误、未知竞争者数量及覆盖组数。小loss不说明困难问题已解决；多数困难竞争unknown时，不将它们直接负标或用伪标签改名为GT。

如果需要人工复核，先确认用户或标注者具有可用判断能力。无法可靠判断时保留unknown，改用既有可靠任务、合法外部监督或其他信息来源；不以强行补负标签维持训练计划。

## 全量训练与采样

用户要求全量训练时，枚举**全部允许且适用的记录**，明确排除项和无监督记录，核对每epoch实际消费情况。资源不足时说明具体瓶颈并采用分片、流式或缓存等实现；不能偷偷缩成固定窗口抽样。若必须改变预算，先说明差异。

探索阶段采样可以合理，但应说明按何规则抽取、哪些场景缺失、监督密度/事件配额偏差及样本重复。报告：

- 允许池：唯一记录数、来源组数、时间跨度。
- 实际读取：唯一记录、有效监督记录、无监督记录。
- 优化器曝光：更新次数、各组/事件的更新次数、重复比例。
- 验证隔离：本轮新增训练、底座、教师的暴露状态。

数据池扩大同时改变采样权重、更新数或调度长度时，列出共同变化，不强行单因归因。全量训练不是所有模型任务都强制必要，但不能把882个窗口称为完整166视频。

## 最终拟合

先在允许的验证方案下冻结结构、训练预算、后处理和融合规则，再决定全量最终拟合。若用户明确要求进行尚未通过本地门槛的最终拟合，执行授权范围并标明证据限制，不自行阻断，也不伪称已验证。

最终拟合吸收验证数据后，原验证只能用于回归检查。不可继续依据它选epoch、调阈值或宣称提升；需要保留有效历史提交及独立评估记录。
